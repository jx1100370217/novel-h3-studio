## 文本边界与改编原则

本次范围是用户提供的这份文本：490,735 字符，497 个物理节，包含 496 篇正文和 1 篇前言，共 2,045 段。首篇《考城隍》为 `s0002`，末篇《爱才》为 `s0497`；编号是本文件索引，不是通行版本的统一篇号。导入报告核对了无缺口、无重叠和原文可完整还原。简介写 491 篇，与实数不一致，保留为版本待核项，不能据此删篇或声称已经校勘权威全集。

《雹神》《三生》《龙》《阎罗》《白莲教》《义犬》各有两个同名条目；按稳定篇 ID 和原文跨度分别保存，不按标题去重。前言、来源说明不生成剧情；篇内资料出处、作者评论分开标注处置，不误判成角色对白。长篇可按自然戏剧节点分集，极短篇保持短篇；先完成该篇全部事实审读，再决定篇幅。

原文事实必须保留证据；改编对白可以将文言、间接引语转成自然白话。合理补足的表演、生活动作、视听连接必须标为“改编选择”。保持人物关系、事件因果、超自然规则和结局；不虚构惩罚威胁、邪恶考官、爱情支线或新的考验。源文本完整保存不等于逐句配一个镜头。核心事实必须真正被观众看到或听到，存在于 JSON 不算完成传达。

## 七场因果链

1. **病中召考。** 宋焘病卧，却被陌生吏员催去赴考。观众必须知道他身体虚弱、召唤不合常理、家中有年迈母亲。对白保留质疑考期；以母亲照料的短动作提前建立牵挂。照料动作和母子简短日常白话为改编选择，不新增人生事件。悬念是“谁会此时召一个病人？”

2. **陌路神庭。** 路陌生、城郭如王都、宋焘认出关帝；张生已在候考。用宋焘视点与少量关系镜头提供空间和身份信息，压缩重复骑行、入门、落座。观众由疑惑转为意识到考试非同寻常；不提前解释生死真相。

3. **考的是人心。** 明确传达试题“一人二人，有心无心”以及宋焘关于善恶动机的作答，再连接诸神赞许与授职。原字由后期准确排版，白话释义可通过阅卷者说出，标为改编选择并核对含义。卷面文字必须可读、停留够用；不能用空白纸替代核心信息。

4. **赴任还是奉母。** 授城隍之职使宋焘明白处境；他因母亲七十且无人照料而请求暂缓。查寿籍得九年，众神迟疑，关帝提出张生代任，宋焘获九年假期。这是主冲突与解法：观众理解他珍惜的不是官位，是尽孝的时间。以请求、等待、回应构成表演，不人为添加拒绝或惩罚。

5. **告别与复生验证。** 张生自报长山人、握手赠诗；自然自报姓名的白话是间接引语戏剧化，诗只保留原文现存句。宋焘回到棺内，母亲扶出；必须清楚传达他已死三日、半日后能说话、张生同日已亡。用角色确认与准确后期时间提示补足，新增说法标为改编选择。回收“奇异考试”悬念，同时证实神庭经历。

6. **九年之约。** 用两三个有前后变化的奉母动作和明确的九年时间提示，连接母亡、营葬、宋焘洗濯入室而没。日常照料为改编选择，不虚构重大事件；衰老沿用同一身份。观众看到九年被真正用于陪伴，也理解宋焘完成承诺后赴任，不能只看到人物接连躺下。

7. **最后一拜。** 岳家先见神仪中的宋焘来拜别，后得知他已亡。传达顺序保留，形成最后一次人间见证；通过亲属反应与简洁的确认信息让超自然告别成立。结尾呼应前面的照料和拜谢，不新增与母亲重逢或惩恶续集。

## 45–75 秒试拍：授职—奉母—九年—代任

目标约 62 秒，允许试读后调整。入口假设：前一场已让观众理解试题、宋焘答卷获赞、宋焘和张生的关系。独立展示试拍时附一句文字说明此入口，不把它冒充完整故事。所有下列白话、眼神、停顿和剪辑安排均为改编选择；对白含义分别锚定原文授职、奉母请求、查册和代任安排。

- **0–8 秒：得到职位，失去确定性。** 从宣命者与宋焘的空间关系起，切到宋焘的理解过程。宣命者：“河南正缺一位城隍，你来任职。”纸页放下声后留一个真实反应停顿。无需新增“你已经死了”的解释。
- **8–24 秒：请求来自具体牵挂。** 宋焘行礼后抬眼：“这份恩典，我不敢推辞。可我母亲已经七十了，身边没人照顾。能不能让我先给她养老送终，再来听命？”同一条完整表演跨镜使用；视点留在请求者，再借听者沉默建立压力。不是三段近景分别从头起势。
- **24–37 秒：等待有结果。** 主位示意查册；先听翻页再切寿册与长须吏，保留宋焘等待的呼吸。“她还能活九年。”回到宋焘反应，让“九年”先被他接收。册上不生成无意义文字；不安排多个人同时念台词。
- **37–53 秒：解法改变两个人。** 众神短暂迟疑，关帝看向张生：“让张生先代你九年。”切张生听见自己名字的反应，再回到关帝：“你回去照顾母亲。九年期满，再来赴任。”张生的反应是接受安排的表演选择，不添加怨恨、承诺或新冲突。
- **53–62 秒：让决定落地。** 宋焘释然但不狂喜，向神庭行礼，与张生交换一次目光；两人退出承接告别场。衣料、脚步、殿内空间余响连续延伸，不用配乐替代情绪，也不让每次切镜都重启房间底噪。

拍摄覆盖按戏剧需要准备关系镜头、请求者中近景、听者反应、寿册插入和张生反应；摄影机遵守已建立的视线轴线。先完整试读对白以校准意图与节奏；正式对白默认来自入选的 H3 联合音画表演，允许其原声跨反应镜头延续。超出单次生成能力的表演按完整意图和自然停顿组织覆盖，不能把临时 TTS 直接贴到无声嘴部画面上。H3 的生成片段可以带余量，正式使用段由编辑决定。紧急规避模型错误时也不能把全部关系戏变成正面证件式特写。
