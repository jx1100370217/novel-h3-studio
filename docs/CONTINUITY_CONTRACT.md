# 镜头连续性契约（全局）

这份契约针对“人物位置关系跳来跳去”的问题。它适用于所有 H3 / FastH3 /
FastVideo / VDN-H3 分镜，不区分项目或故事。

## 1. 同场镜头必须有连续性参考

一个场景的第一镜可以用 cast + scene 参考建立空间；**之后的每一镜**必须至少
携带一种连续性参考：

- **`<Video N>` 续接**（默认）：上一故事镜的静音尾段 2–4 秒，保留结束姿势、
  手/道具位置、服装、光线和屏幕方向；不复制构图、剪辑、运镜、旧对白或音频。
- **previs 白模/ blocking 图**：多人镜头没有可续接的上一镜时，用 Blender
  灰度白模或等价的 2D 灰度站位图锁定人数、位置、姿势、屏幕方向和机位。

只给 cast + scene 参考、不给连续性参考，是位置跳变的直接原因。V3 的 S02/S03
就犯了这个错：spec 里 `videos=0`、`previs=0`，每镜独立生成，人物距离和朝向
自然会对不上。

`build_spec(continuity_required=True)` 在没有 `<Video N>` 且没有 previs 时
直接报错：

```
same-scene continuation needs a <Video N> tail or a previs blocking guide
```

## 2. 插入镜可以锚到最后一个故事镜

水下、手部、道具等 insert 不需要从上一 insert 续接；它可以锚到**最后一个
故事状态镜**的尾段。例如：

```
S02D0 空网（故事镜）
S02D1 王六郎点水（故事镜）
S02D   水下鱼群（insert，不续接）
S02D3 满网（续接 S02D1，而不是水下 insert）
```

## 3. 白模不可用时

Blender 未安装时，不允许退回“只给 cast + scene”。可用：

1. `<Video N>` 续接（首选）；
2. 2D 灰度站位图（PIL/SVG 生成，人物用灰色剪影，标出左右、远近、机位）；
3. 明确记录人工豁免，并说明为什么该镜不需要连续性。

## 4. 因果动作要拆成可见的镜头

“王六郎帮许某抓鱼”不能只靠水下鱼群突然转向。生产上拆成：

```
空网（需要） → 王六郎点水/我帮你（施动） → 水下鱼群（效果） → 满网（结果） → 船倾（后果）
```

每个动作镜都有 open_state / close_state，并续接上一故事镜的结束状态。

## 5. 新故事如何继承

1. 场景第一镜用 cast + scene（多人镜头加 previs）；
2. 后续每镜在 authoring 里写 `previous`，由 builder 生成 `<Video N>`；
3. 插入镜写 `previous` 指向最后一个故事镜，或明确不续接；
4. 跑 `build_spec` 时 `continuity_required=True` 会强制检查；
5. 渲染后抽查相邻镜的最后一帧/第一帧，位置、朝向、道具和光线必须接上。
