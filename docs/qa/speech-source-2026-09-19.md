# H3 非对白人声源头核查（2026-09-19）

## 已确认的问题

- director 提示词编译器屏蔽了场景定妆说明，但身份表仍发送角色中文定妆说明及视角标签。中文名称也出现在 camera focus 等段落。它们进入与对白相同的模型文本输入；“禁止朗读”不能隔离它们。
- Ref2VA 的 ref_audios 接口对整段波形做 VAE 编码，作为参考 latent 输入，没有专用的纯音色向量提取开关。东极青华大帝参考音频长 4.08 秒，独立转写为“冬极清华大帝先护住伤者，再追查异变的源头”。名册 transcript 字段却只是“仅作为音色参考，不复制参考台词”，不能当作真实转写。
- C4D034 与 C3D025 均为 cut，未载入前镜 latent。不能把这两例归因于 Motion Context。也不能用音频上下文长度调节解决独立切镜问题。
- 提示词同时要求全部动作时间线、末尾回头安排对白，并写“说不准确就静音”。这是冗余及冲突风险；这些文字从来不是模型采样约束。

## 实施的输入层修复

所有项目的执行单、普通提交和重拍共用同一编译入口。画面元数据与对白分开，名字改为对应 Subject 编号，删除传给模型的中文定妆说明及视角标签；未处理的块外中文直接阻止提交。发声块逐条等于批准的对白，不能从 action 注入额外对白。时间事件按顺序交错，不再改写特定镜头的对白标点。dialogue_only 项目禁止旁白声音绑定。

编译了当前两个正式章节共 66 个镜头；这是现有正式镜头数量，不代表全书全部章节已制作。已有渲染档案保留原始输入，不篡改历史。当前两个项目关闭自动音频清洗。98 项单元测试通过。

## 结论与未完成项

输入泄漏修复不能保证概率音画联合模型不补词。此实验没有单独消融参考音频，因此不能声称已经证明多余声音就是复制参考语音；也没有测试禁用 Turbo，不能把问题归咎于 8 步适配器。

严格要求确定的对白音轨，需要先生成、核对逐句音轨，再验证支持固定音轨驱动画面的方案，包括保持角色音色、口型同步与原有音效。该替代链路尚未实现或验证，不能把 Add Guide 或普通 timbre reference 当成硬锁定音轨。生产批量生成在验证失败后暂停，等待该架构选择；现有视频未删除。
