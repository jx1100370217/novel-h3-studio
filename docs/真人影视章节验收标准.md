# 真人影视章节制作与验收标准

本标准用于分镜编写、资产绑定、Blender 白模预演、H3 生成和章节合成；章节完成不以“模型返回成功”或“视频文件存在”为准。

## 依据

- shuohao-skills 将改编剧本与导演分镜分层，要求剧本节拍先确定，再由分镜覆盖节拍；按场景组织动作和对白，并保留原文依据、角色与资产台账。[项目 README](https://github.com/eternityspring/shuohao-skills)、[novel-script 技能](https://raw.githubusercontent.com/eternityspring/shuohao-skills/main/skills/novel-script/SKILL.md)、[novel-storyboard 技能](https://raw.githubusercontent.com/eternityspring/shuohao-skills/main/skills/novel-storyboard/SKILL.md)
- BBC Academy 的制作教学强调对话轴线两侧机位须保持一致，运动方向连续，避免观众误读人物路线。[Crossing the Line](https://downloads.bbc.co.uk/academy/collegeofproduction/docs/crossing_the_line_movement_ts.pdf)、[Getting the Shot Right](https://downloads.bbc.co.uk/academy/academyfiles/TVNewsInterviewing/Interviewing%20-%20Getting%20the%20shot%20right.pdf)
- eyeline、动作衔接、空间关系和180度轴线是连续性剪辑的基本工具；越轴应有明确叙事动机。[StudioBinder：Continuity Editing](https://www.studiobinder.com/blog/what-is-continuity-editing-in-film/)、[Screen Direction](https://www.studiobinder.com/blog/what-is-screen-direction-in-film/)

## 编剧和分镜硬门槛

1. 每个场景说明人物此刻要什么、遇到什么信息或阻力、产生什么动作/决定/后果；不得把“原文段落”机械地直接当镜头。
2. 所有画面事实可追溯到原文段落；原文未写的造型/调度须标成改编选择。对白和说话人逐字锁定；旁白只能提供画面参考，不能进入语音轨。
3. 每镜有明确的戏剧作用、开始状态、演员走位、结束状态、资产绑定、景别、焦距、机位、运镜理由、屏幕方向、场景轴线与转场方式。对白镜头按内容时长；镜头最长15秒。安静的反应/连接镜头短而有信息，通常2–4秒。
4. 同一场景固定空间布局、人物左右关系和视线。入场/离场必须写清起点、路径、终点；“走来/出现/抵达”不能作为完整调度。登场人物、数量、身份不得跨镜跳变。
5. 同一说话者的连续对白使用一致场景与轴线；说话者画面、对白和参考音频一一绑定。监听者嘴部保持静止。无对白镜头不附参考音频、不产生人声。
6. Blender 白模按绑定演员资产逐个生成代理人，执行镜头中的落点与运动路径；逐帧检查代理人画面投影，绑定角色不应意外出画或缩成不可辨识的小点。

## 成片检查与评分

每个镜头对照执行单检查：剧情/原文、人物身份和数量、空间及场景资产、动作与道具连续性、画面构图和运镜、对白与音频。章节检查镜头衔接、节奏、场景连贯和声音整体。

每项按 1–5 分记录。交付需整体平均分至少 4 分，任一项不得低于 3 分；以下问题均为直接不通过，不允许用平均分抵消：对白错配/缺失/重复、未登记对白人声、绑定角色遗漏或重复、场景错误、严重空场替代人物、明显反向走路/瞬移/缩放、动作在剪辑点断裂、文件损坏或章节合成顺序错误。

自动检查包括原文和对白哈希/逐字相等、说话人绑定、场景/角色/道具资产覆盖、H3 单镜上限及时间线完整性、白模角色资产与走位清单相等、白模代理人投影。人工画面检查覆盖每镜首帧、中段、末帧及完整播放；对白逐条听审，静默镜头做人声检测，章节合成后再完整抽查剪辑点与声轨。

每轮验收必须把失败镜头、可观察证据、对应执行单字段和提示词来源写进报告，只修改根因对应的全局规则或镜头设计；重新生成后复查同一项并记录是否通过。
