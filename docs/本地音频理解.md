# 本地音频理解与审片

已在本机部署并用真实影片音轨测试。入口：[小说电影工作台](http://127.0.0.1:8765) → **音频审片**。也可在“看片与验收”中点击“分析这条视频的声音”。

输入本地 MP4、MKV、MOV、WebM、WAV、MP3、M4A、AAC、FLAC 或 OGG 文件，得到对白候选稿、分段时间戳、环境声描述、音乐判断、分类分数、可播放的音轨和完整报告。当前选取第一条音轨，默认中文，支持自动语言检测与英语。所有推理使用本机缓存，不上传音视频，不调用付费 API。

## 实际验证

2026-09-14，RTX 5090 32 GB，Python 3.13.13，Torch 2.13.0+cu130，Transformers 5.16.1，Librosa 0.11.0。

| 素材 | 结果与证据 |
| --- | --- |
| 实际 H3 两镜开场，约 10.84 秒音轨 | Qwen 判断风声、流水声、雷声，无明确对白和音乐；AST 以浪、水、雷和风为主要类别。Whisper 错写“字幕志愿者……”；系统标记模型冲突，未把它加入候选字幕。 |
| Qwen 官方公开中文样例，4.20 秒 | Whisper 和 Qwen 都识别出“甚至出现交易几乎停滞的情况”；候选 SRT 生成并核对。音乐判断为不确定，保留原结果。 |
| 本地合成四组和弦，8 秒 | 仅作音乐识别阳性对照。通过真实网页启动分析，Qwen 判断有音乐、无对白，噪声转写被拦截。此文件没有用于影片。 |

固定样本实测不能代表各种人声、混音和噪声条件下的准确率。模型加载缓存热启动时，这两段短素材各处理约 5 秒；首次加载和长片处理会更久。

浏览器实际验证了分析按钮、进度更新、报告展示、音频 Range 读取和开场视频加载；页面截图保存在 `docs/qa/audio-review.png`、`audio-music-control.png` 和 `opening-preview.png`。中文测试报告保存在 `docs/qa/audio_tests/chinese_speech/`。

## 命令入口

前台执行，适合 Codex 直接取得分析报告：

```bash
/home/jx/codes/novel-h3-studio/listen_audio /absolute/path/video.mp4 --out /absolute/path/review
```

工作台后台执行，返回任务 ID，结果在网页自动刷新：

```bash
cd /home/jx/codes/novel-h3-studio
python3 studio.py listen /absolute/path/video.mp4
```

默认显卡理解；需要约 18 GB 空闲显存。网页与 `studio.py listen` 在视频任务仍运行时明确拒绝显卡分析，任务完成后会释放本项目空闲的视频模型。它们不打断其他项目，也不停止正在运行的影片任务。CPU 模式 `--device cpu` 可以在生成影片时使用，但 7B 模型明显较慢并需要足够内存。前台入口只检查实际显存，不操作 ComfyUI。网页、CLI 与视频提交会避免本项目同时启动两项显卡任务；其他进程独立使用显卡仍可能导致显存不足。

输出目录包含：`report.json`、便于阅读的 `report.txt`、`audio_16k.wav`、`transcript_candidate.srt` 和 `progress.json`。工作台后台任务另存 `run.log`。原文件 SHA-256、音轨信息、模型版本和分析分段均保存在报告中。

## 审片边界

本地模型分析让 Codex 可以读取声音证据，**不会改变当前 Codex 模型本身不接收音频输入的限制**。不能把模型输出描述成“我亲耳听过”。

Whisper 在无对白音效和音乐上可能幻听。只有 Qwen 同时判断存在语音时，Whisper 时间戳候选才进入 SRT；模型冲突保留在报告，不静默删掉原始转写，也不会被写进正式字幕。人名、方言、弱对白、口型和声线一致性仍需复核。分类分数未经本片校准，低音乐分数不能证明绝对无配乐。

每 20 秒做一次转写与理解，事件分类再拆为不超过 10 秒的片段，覆盖末尾短段。分段边界没有语义续接，边界处对白可能不完整。输出的波形峰值和 RMS 是混为 16 kHz 单声道后的测量，不是原始多声道响度或同步验收。

`release_approved` 永远为 `false`；音频分析不会绕过逐镜审片或全书覆盖检查。生成 H3 时继续使用无配乐设置；阳性对照仅用于测试识别能力。

中文验证音频来自 [Qwen3-ASR 官方 README](https://github.com/QwenLM/Qwen3-ASR)，具体样本地址和合成对照说明保存在 `runtime/audio_test/sources.json`。
